# Wedding Hamper Lucky Draw

A beautiful bingo number generator (1–75) for the wedding hamper lucky draw.

- **Draw Number** button (or Spacebar) with a slot-machine animation and confetti
- Giant display ball with the BINGO letter + number
- Full 1–75 called board, recent-calls strip, called/remaining counters
- **Override**: mark numbers called offline — they're blacklisted exactly as if the generator picked them
- Game state persists in `localStorage` (survives refresh)
- "New game" reset button

Static site — no build step. Deploys to Cloudflare Pages / GitHub Pages as-is.
